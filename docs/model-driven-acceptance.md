## 效果边界与成本

24个场景变体已定义，不是24个付费场景全部通过。新协议的会话指代、注入防护、完整多轮更正等具备工程测试，但仍缺完整真实模型覆盖；不能据此宣称模型泛化能力已完成全量验收。

所有已完成 API 响应共报告111,306 tokens；初轮中断请求用量未知。将初轮全额预算计入，保守总上界为165,938 tokens，低于两轮180,000总上限。未继续扩大付费验证。

模型决定行动与目标，代码校验参数、授权、审批、证据和执行边界。目标理解是否遗漏语义仍由独立场景检查。最终答复采用模型组织的事实占位符和经过校验的事实句，未开放不受约束的自由事实陈述。
